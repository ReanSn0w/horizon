## Horizon v0.2.0

Завершён этап рефакторинга Horizon. Оставшиеся структурные перестановки сняты с плана; выпуск включает готовые изменения ядра, менеджера и плагинов.

### Основные изменения

- Установка и обновление из исходников через `horizon-manager`, управление плагинами и rollback.
- Управляющий процесс `horizon agent`, адаптеры Telegram и таймеров, делегирование через subagent.
- Управление навыками, встроенные memory/decision, уточнения во время активного хода.
- CLI плагинов на `go-flags`, исправленная таблица плагинов.
- Бережная актуализация конфигурации менеджером с сохранением значений, комментариев, symlink и прав доступа.
- Генерация и установка файлов systemd/LaunchAgent через `horizon agent service print|install`.
- `horizon telegram check` и явная тестовая отправка `horizon telegram send TEXT` без модели.

### Бинарники

| Система | Архитектура | Файл |
| --- | --- | --- |
| Linux | amd64 / x86_64 | `horizon-manager-linux-amd64` |
| Linux | arm64 / aarch64 | `horizon-manager-linux-arm64` |
| macOS | Intel / amd64 | `horizon-manager-darwin-amd64` |
| macOS | Apple Silicon / arm64 | `horizon-manager-darwin-arm64` |

`SHA256SUMS` содержит SHA-256 всех четырёх бинарников. Каждый вариант собран и проверен на нативном runner соответствующей платформы. macOS-бинарники не имеют Developer ID/notarization.

Скачайте нужный файл, проверьте SHA-256 и добавьте право исполнения (`chmod +x`). Запустите его с командой `install`. Менеджер собирает Horizon на вашей машине, поэтому нужны Git и Go версии из `go.mod` устанавливаемой ревизии (для v0.2.0 — Go 1.26.7).

### Обновление

Остановите работающие ходы и службы. Для перехода со старой установки используйте скачанный **новый менеджер**, затем выполните `update --home /absolute/path/to/home`. Старый менеджер не знает нового имени управляющего плагина.

Управляемый `daemon` заменяется на `agent`, настройки переносятся в `plugins.agent`; пути очереди, сокета и постоянных блокировок сохраняются. `mode: unit` больше не требуется и удаляется при актуализации конфигурации. Неоднозначные старые настройки и неизвестные поля не удаляются автоматически.

Определения служб обновляются отдельно. Сессии, память, пользовательские инструкции и навыки сохраняются. Подробнее: [Manager](https://github.com/ReanSn0w/horizon/blob/v0.2.0/plugins/manager/README.md) и [Agent](https://github.com/ReanSn0w/horizon/blob/v0.2.0/plugins/agent/README.md).
