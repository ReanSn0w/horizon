# Decision

`horizon decision request.json` или `horizon decision - -o result.json`
принимает ровно один путь к UTF-8 JSON-файлу; `-` читает stdin. Флаг `-o`
допускается до или после пути. `--help` и `-h` показывают локальную справку.

Вход — один объект `{state, questions}` без других верхнеуровневых полей.
Вопросы используют типы `noul`, `choice`, `score`, непустые имена и
`instructions`; необязательные `criteria` передаются провайдеру.
Лимит сериализованного запроса с настроенной моделью — 32 КиБ.

```json
{"state":{"proposal":"release version 1.2"},"questions":{"ready":{"type":"noul","instructions":"Is the proposal ready to release?"}}}
```

URL, ключ и модель берутся из общей секции `decision` в
`HORIZON_HOME/config.yaml`. Вход и аргументы не переопределяют их.
Успешный ответ — один JSON-объект (`id`, `model`, `provider`, `answers`,
`usage`) с переводом строки. Без `-o` он идёт в stdout; с `-o` атомарно
заменяет файл с правами `0600`, stdout остаётся пустым.
Диагностика идёт только в stderr. Код 2 означает неверные аргументы,
вход или конфигурацию, 1 — ошибку провайдера или вывода, 130 — отмену.
Метаданные и справка не читают конфигурацию и не обращаются к сети.
Плагин не создаёт ход агента и не меняет сессии.
