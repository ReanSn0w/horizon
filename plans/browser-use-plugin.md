## Что мы делаем?

Добавляем устанавливаемый Go-плагин `browser` для управления удалённым Chromium через Browser Use Browsers API v4 и CDP. Модель получает типизированные инструменты плагина; локальный браузер, отдельный демон, навык с командами `shell_exec` и делегирование задачи агенту Browser Use не требуются.

Браузер создаётся только при первом открытии URL в ходе Horizon, используется последующими браузерными вызовами этого хода и автоматически останавливается хостом при завершении хода, включая ошибку и отмену. Новый ход начинает без браузера. CLI-команды `horizon browser list` и `horizon browser close` позволяют проверить и закрыть оставшиеся сессии после падения процесса без участия модели. Первая версия работает с публичными страницами и текстовым снимком структуры страницы: переход, чтение, нажатие и ввод обычного текста. Снимки экрана, загрузка файлов, перенос профилей и ввод секретов в объём первой версии не входят: текущий протокол ограничивает ответ плагина 64 КиБ, а аргументы инструментов сохраняются в истории.

## Для чего мы делаем?

У Horizon уже есть протокол расширений агента и настройки `plugins.<имя>`, но нет завершающего вызова плагина после хода. Вызовы плагина выполняются отдельными процессами, поэтому удалённую сессию нельзя держать только в памяти процесса. Browser Use останавливает оплачиваемый браузер отдельным API-запросом; отключение CDP-клиента не заменяет остановку. Нужны учёт состояния по `turn_id`, автоматическая очистка и ручная проверка с закрытием после обрыва процесса. Список браузеров Browser Use v4 фильтруется по меткам, поэтому CLI может найти сессию даже при потере локальной записи.
