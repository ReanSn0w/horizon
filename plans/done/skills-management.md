## Что мы делаем?

Добавляем локальные команды управления навыками выбранного Horizon home:

```sh
horizon skills list
horizon skills validate --id review-go
horizon skills disable --id review-go
horizon skills enable --id review-go
horizon --home /path/to/home skills list
```

`list` показывает таблицу `ID | NAME | DESCRIPTION | ACTIVE`, включая отключённые
навыки. `validate` проверяет файл на диске и сообщает об ошибках формата.
Модель вызывает команды через существующий `shell_exec`; проверка не требует
обращения к модели, провайдеру или создания сессии.

Предлагаемый ID — имя непосредственного подкаталога `<home>/skills/`.
Он не зависит от корректности YAML и может отличаться от `name` в заголовке.
Дополнительная колонка ID позволяет скопировать адресуемый идентификатор из таблицы.
Существующий `skill_read(name)` сохраняет обращение по имени из YAML.

Состояние хранится в верхнеуровневом поле `config.yaml`:

```yaml
disabled_skills:
  - review-go
```

`disable` добавляет ID без дубликатов, `enable` удаляет его. Отсутствующее поле
равнозначно пустому списку. Изменение действует для следующего снимка инструкций;
начатый ход использует прежний каталог. Отключение исключает навык из каталога
модели и `skill_read`, но не удаляет его файлы и не ограничивает файловые инструменты.

Используем существующие Go, `go-flags`, `text/tabwriter` и `yaml.v3`.
Новые зависимости, отдельное хранилище, новые function tools, установка и удаление
навыков, автоматическое исправление файлов в эту задачу не входят.

## Для чего мы делаем?

Сейчас `ScanSkills` останавливает загрузку всего каталога на первой ошибке,
отключения отдельных навыков нет, а встроенный `skill-creator` проверяет
созданный файл только вручную. Полная загрузка конфигурации дополнительно
требует готовых настроек провайдера.

Нужно дать пользователю и модели возможность перечислить навыки, проверить
конкретный файл и отключить проблемный навык независимо от работоспособности
остальных навыков и готовности API. Проверка должна читать свежий файл даже
в ходе, который начался до создания навыка.
