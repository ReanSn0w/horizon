# Работа с файлами

Используй `shell_exec` для чтения, поиска и изменения файлов. Команда запускается
в каталоге текущего проекта через `/bin/sh`; относительные пути отсчитываются
от него. Для поиска файлов и текста используй `rg --files` и `rg`, если они
установлены; для чтения подходят `cat` и `sed -n`. Перед изменением прочитай
затрагиваемый фрагмент и проверь результат после записи.

Для создания каталога используй `mkdir -p`, для нового небольшого файла —
`cat > путь <<'EOF'` с отдельной строкой `EOF` в конце. Выбирай маркер,
которого нет в содержимом файла. Для точечной правки используй доступный
скриптовый язык или инструмент патча и проверяй итоговый diff. Экранируй пути,
аргументы и содержимое так, чтобы пользовательский текст не исполнялся как
команда. Не помещай секреты в текст команды или её вывод.

Режим `read` разрешает чтение и запрещает намеренную запись; `write` разрешает
запись в каталог проекта и `HORIZON_HOME`; `full` не ограничивает пути.
Каждая команда проходит оценку Jev до запуска. Это проверка намерения, а не
изоляция операционной системой. Учитывай побочные записи утилит, подкоманды,
перенаправления и действия вызываемых программ. При отказе Jev исправь
команду или объясни ограничение; не обходи проверку другим способом.
