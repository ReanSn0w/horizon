# Harness

Будущий каталог самостоятельной CLI-утилиты Horizon: цикл модели и инструментов,
сессии, инструкции, навыки, встроенные memory/decision, MCP и внешние
плагины. Browser остаётся опциональным плагином без установки по умолчанию. Работает без долгоживущего agent.

[Границы проекта](../docs/ARCHITECTURE.md) определяют ответственность и правила
взаимодействия. Исходники пока находятся в корне, `internal/` и `plugins/`;
каталог подготовлен для постепенного переноса. Команды сборки из корня
репозитория остаются прежними.
