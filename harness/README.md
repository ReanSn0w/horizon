# Harness

Самостоятельная CLI-утилита Horizon: цикл модели и инструментов, сессии,
инструкции, навыки и подключение внешних плагинов. Работает без долгоживущего agent.

Из корня репозитория:

```sh
go build -o /tmp/horizon-dev ./harness
go test ./...
go vet ./...
make install
```

`make install` устанавливает бинарник с именем `horizon`. Корневой `go.mod`
общий для harness, текущих плагинов и релизных утилит. Закрытая реализация
находится в `internal/`; пакеты, необходимые существующим внешним компонентам,
размещены непосредственно в этом каталоге. Публичный Go SDK не предоставляется.

Memory и decision пока остаются отдельными CLI-плагинами; механизм проверки
команд decision уже используется ядром. Встраивание возможностей этих плагинов
и поддержка MCP — следующие задачи. Browser остаётся опциональным плагином
без установки по умолчанию.

[Границы проекта](../docs/ARCHITECTURE.md) описывают целевую архитектуру,
а [корневой README](../README.md) — текущие команды и конфигурацию.
