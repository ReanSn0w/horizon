## Проверка реализации — 13 ноября 2026

- Пользовательские команды плагинов используют `go-flags`; внутренние команды JSON-протоколов остаются отдельными.
- `mode` удалён из рабочего типа и шаблонов. Старое `mode: unit` принимается при чтении; manager удаляет его при переходе на новую ревизию и сохраняет для старых исходников.
- `horizon agent service print|install` создаёт unit/plist и печатает команды запуска; сам службу не активирует. [Переход с daemon и установка службы](plugins/agent/README.md).
- Пройдены `go test ./...`, `go test -race ./...` (и повторная race-проверка поздних изменений), `go vet ./...`, сборка, `git diff --check`, проверка локальных ссылок. Сгенерированный plist проверен через `plutil -lint`.
- Миграция и rollback проверены на временных home; Telegram — на локальном HTTP-сервере без модели. Реальные службы ОС и реальный Telegram не запускались.
