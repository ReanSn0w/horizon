# Замечания и доработки Horizon

Рабочий список замечаний, найденных при проверке ветки рефакторинга.
Добавляем сюда согласованные доработки; выполненные пункты отмечаем `[x]`.

## 12 ноября 2026

- [ ] Привести CLI плагинов Horizon к использованию `go-flags`: описывать параметры и команды через библиотеку, формировать справку по этим описаниям. Убрать самодельные принты с описанием параметров и использования.
- [ ] Исправить выравнивание столбцов в выводе `horizon manager plugins list`: заголовки и значения должны образовывать ровную, читаемую таблицу при разной длине названий плагинов.
- [ ] Согласовать название управляющего процесса и префикс его плагинов: сейчас процесс называется `daemon`, а его адаптеры — `agent-*`. Выбрать единое именование: переименовать адаптеры в `daemon-*` либо управляющий процесс под имя `agent`. Направление переименования пока не выбрано; согласованно обновить команды, бинарники, обнаружение плагинов, настройки и документацию.
- [ ] Удалить параметр `mode` из конфигурации: запланированные сценарии его использования больше не нужны. Убрать связанное поле, валидацию и зависимую логику; обновить шаблоны конфигурации, тесты и документацию. Учесть переход существующих конфигураций с `mode` на новый формат.
- [ ] Добавить для daemon Horizon создание и установку файлов службы ОС: unit-файла systemd в Linux и plist для LaunchAgent (launchd) в macOS. В определении службы учитывать путь установленного бинарника и выбранный `HORIZON_HOME`; документировать запуск и автозапуск службы.
- [ ] Обеспечить простой способ проверить настройки Telegram из CLI без обращения к модели. Сейчас `horizon telegram send 'hi!'` безусловно возвращает сообщение об удалённой команде, не проверяя настройки и не отправляя сообщение, хотя `send` всё ещё указан в справке. Согласовать справку с доступными командами и определить интерфейс проверки подключения и тестовой отправки.
